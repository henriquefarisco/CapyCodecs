# Ogg packet reader (development)

`src/audio/ogg_reader.{h,c}` is a private precursor to Vorbis decoding, not a
public `capy-codec-audio` capability. WAV remains the only implemented public
audio decoder. No ABI version, feature bit or production pin changes here.

The reader follows [Xiph's Ogg framing specification](https://www.xiph.org/ogg/doc/framing.html)
for page headers, direct CRC-32, segment lacing and packet continuation.
It deliberately accepts only one complete logical stream starting at BOS and
ending at EOS. Chained/multiplexed streams and trailing data are rejected;
resynchronization is not attempted. It publishes page granule positions on the
last completed packet but does not interpret their codec-specific meaning or
validate Vorbis headers/codebooks/audio. A returned packet is not
evidence that the rest of the stream is valid: callers must drain through verified
EOS, and reject a later error rather than treating it as normal completion.

## Bounds and ownership

- Input is immutable and borrowed for the reader's lifetime; the caller owns all
  input/state/packet scratch memory. Scratch must not overlap the input or state.
- Explicit input, page-count and cumulative packet-byte budgets are required.
- CRC work is linear in bounded input, with at most 65307 bytes per page.
- Each call emits one packet (zero-length packets are valid), EOF, or a sticky
  error. Packets spanning pages are assembled in caller scratch without heap use.
- No callbacks, filesystem, network, platform headers or global allocator.
- This is incremental packet delivery over a complete memory input, **not** a
  streaming feed API or incremental PCM decoder.

## Evidence (2026-09-06)

`make validate` passed image, WAV and new Ogg tests. The Ogg test includes a
fixed page/CRC independently generated by installed Xiph `libogg.so.0` using
`ogg_page_checksum_set`, multiple and empty packets, exact-255-byte termination,
multi-page reconstruction, empty continuation pages, sequence/serial/flag
failures, missing EOS, trailing data, page/input/packet budgets, every truncated
prefix and single-byte mutation of the multi-packet fixture, plus 10000 seeded
mutations whose CRC is recomputed to exercise deeper framing checks.

ASan/UBSan passed the same test. A freestanding build with `-fno-builtin` compiled
and `nm -u` reported no undefined symbols. Logs: `build/ogg-validation.log` and
`build/ogg-sanitizers.log`. These bounded synthetic mutations are not a claim of
coverage-guided fuzzing or differential Vorbis decoding.

No CapyOS runtime consumer was connected, so no new VM gate is claimed. Private
Vorbis header/setup, packet entropy and float PCM synthesis now exist with host
reference evidence. Public ABI integration, a player consumer and fresh
QEMU/VMware playback remain subsequent gates.

The reader now retains the 64-bit granule position of each page and publishes
it only on the last completed packet of that page, matching Ogg packet/granule
semantics. Earlier packets on a multi-packet page correctly report no granule;
a completed packet followed only by an unfinished continuation still receives
the page granule. The real Vorbis host harness uses the final packet granule to
trim synthesis tail frames.
